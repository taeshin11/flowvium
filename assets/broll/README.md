# b-roll 클립

사람이 직접 넣는 배경 영상. **파일은 구글드라이브에 둔다** —
`내 드라이브/FlowVium-media/broll/`

- 파일명이 곧 검색어다. `us-capitol-dome.mp4` → "capitol", "dome" 으로 매칭된다.
- 매칭은 **4글자 이상 낱말**만 본다. `us-…` 의 "us" 는 안 걸린다
  (2026-08-27: 2글자 매칭 때문에 우편·트럼프 장면에 국회의사당이 깔렸다).
- 라이선스 판단은 넣는 사람 몫이다 — 파이프라인은 여기 있는 파일을 검사하지 않는다.

이 폴더(`assets/broll/`)는 하위호환으로 계속 읽지만, 드라이브 쪽이 우선이다.
